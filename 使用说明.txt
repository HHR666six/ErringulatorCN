艾尔登法环 效果随机化器（ErringulatorCN）1.6.0
====================================================

把魔法、祷告、战灰、道具、装备、敌人的效果互相换主——名称与图标不变，
实际效果变成别人的（以撒「错误道具」式）。另完整集成 Elden Ring
Summon Randomizer（骨灰换敌 / 多召 / 驯服克隆 / 强化倍率 / 六套预设）。

支持游戏 1.16.x（含《黄金树之影》DLC）。标题栏与运行日志都会显示版本号；
完整变更记录见 GitHub Releases。

一、它能做什么
----------------------------------------------------
1. 效果错位：魔法与祷告、战灰、道具、装备（护符/武器）的效果互相换主。
   子项「攻击元素」把元素错位延伸到攻击判定层——刀可能砍出火、法术
   可能劈出雷，命中特效随之变化。
2. 敌人与战斗：敌人伤害抗性随机、敌人韧性随机。两项都分「非Boss / Boss」
   两个范围，两池独立置换（BOSS 只与 BOSS 互换）。
3. 召唤物随机化：骨灰召唤出的敌人随机化（换敌 / 多召 / 驯服 / 倍率）。
4. 附加（默认关闭）：NPC 对话随机、武器动作模组随机。

二、运行要求
----------------------------------------------------
* 游戏版本 1.16.x（含 DLC），Steam 版。
* 自包含单文件，无需安装 .NET；双击 ErringulatorCN.exe 即可。

文件说明（本目录）：
  ErringulatorCN.exe      主程序
  ErringulatorCN.Cli.exe  命令行工具（可选，进阶排障用）
  paramdefs\              参数表定义（194 个 xml），必须与 exe 同目录
  使用说明.txt            本文件
  src\                    全部源码与构建说明（仅完整源码目录包含）

三、使用步骤
----------------------------------------------------
1. 解压到任意位置，不要在压缩包里直接运行。
2. 先备份：复制一份游戏目录的 regulation.bin（通常在
   ...\steamapps\common\ELDEN RING\Game）。
3. 双击 ErringulatorCN.exe；会自动找 Steam 安装目录（支持多库），
   找不到就手动选。
4. 「游戏目录」选包含 regulation.bin 的目录。
5. 「输出目录」默认是程序目录下的 output；想直接替换游戏文件就设成
   游戏目录本身（会自动生成 regulation.bin.bak，可随时「恢复备份」）。
6. 勾选要随机化的内容、选错位方式，点「开始随机化」。
7. 等约 25 秒，重启游戏后生效。
8. 日志末尾的「关键道具保护自检」应全部为「未被改动」；日志会自动保存到
   输出目录（ErringulatorCN_log_日期-时间.txt）。

四、选项说明
----------------------------------------------------
【主界面 · 效果错位】
  魔法与祷告        释放法术时打出别人的法术效果
  战灰              动作与速度换成别的战灰
  道具              使用效果换主——喝药可能触发别的效果
  装备效果          护符与武器附带效果换主，护符会真正生效别人的能力
    ↳ 攻击元素      刀可能砍出火、法术可能劈出雷，命中特效跟随变化
                    （需勾选「装备效果」；默认关闭）

【主界面 · 敌人与战斗】
  敌人伤害抗性随机  抗性换主：怕毒的敌人可能不再怕毒，弱火的 BOSS 可能变弱雷
    ↳ 非Boss类敌人  杂兵/精英/野生动物参与（默认勾选）
    ↳ Boss类敌人    BOSS 参与，只与其他 BOSS 互换（默认不勾选）
  敌人韧性随机      韧性档位换主：原本一碰就失衡的杂兵可能扛住一击，
                    高韧性 BOSS 可能变得容易失衡（默认关闭）
    ↳ 非Boss类敌人 / ↳ Boss类敌人   同上，两池各自独立

【主界面 · 扩展玩法】
  NPC 对话随机      NPC 说别人的台词，动作与口型跟随；不影响任务逻辑
  武器动作模组随机  用别的武器的攻击动画，手感与攻击距离随之变化
  启用召唤物随机化  骨灰召唤出的敌人随机化（展开下方可详细设置）

【主界面 · 其他】
  道具保守筛选      只让真正能用且带效果的道具参与（默认开启，建议保持；
                    取消后容易破坏游戏功能）
  解除战灰武器限制  任意武器都能装任意战灰（默认开启）
  资源消耗也随机    MP / 耐力 / 使用次数也一起错位
  武器挂载战灰也换  更混乱（默认关闭）
  包含 NPC 专用法术 敌方法术也参与错位，可能造成异常行为（默认关闭）

【召唤物面板 · 默认「完整」模式】
  完整   随机换敌 + 按几率多召 + 克隆驯服 + 消耗重掷 + 强化倍率
  温和   只把现有召唤条目的敌人互换，不新增/克隆
  预设   六套（欢乐 / 合理 / 混沌 / 家族 / 游乐场 / 均衡），数值与原版
         Summon Randomizer 一致，选中即套用；设置串与原版互通，可互抄
  数值   初始多召几率、追加几率、多召上限（1 = 不多召）、重复几率、
         变体复用、允许骨灰重复、禁止大体积多召、骨灰消耗重掷
         （FP 30~60，10% 改消耗 HP 300~600）、血量/伤害/FP 倍率
         （1.0 = 不变，与骨灰强化加成叠加而非覆盖）

【错位方式】仅影响效果错位
  完全洗牌（推荐）  最像「错误道具」
  顺移             整体向后平移 N 位
  倒序             顺序完全反转

【随机种子】
  留空 = 自动生成。相同种子 + 相同设置 + 相同原始文件 = 完全相同的结果。
  界面上的目录与选项会自动记住（%LocalAppData%\ErringulatorCN）。

五、安全与注意事项
----------------------------------------------------
* 修改后的 regulation.bin 严禁联机使用（有封号风险），请离线游玩。
* 永远保留原始 regulation.bin 备份；本工具只改这一个文件，不碰存档与本体。
* 关键道具（灵马哨笛、望远镜、携带照明灯、圣杯瓶等 9 项）受保护，
  每次生成后看日志自检是否全部「未被改动」。
* 修改后必须重启游戏才生效。
* 禁止双开：第二个实例会提示「程序已在运行」并退出，避免互相覆盖输出。
* 数字输错会明确报错并定位到输入框；越界数值按上限处理并在日志说明。
* 稳定性与不变性由项目内自动化回归覆盖（确定性 / 只重打包零差异 /
  关键道具保护），可放心重复使用。

六、常见问题
----------------------------------------------------
Q 提示「找不到 paramdef 定义目录」
A paramdefs 文件夹必须与 ErringulatorCN.exe 同层，不要只复制 exe。

Q 报错「Access to the path ... is denied」
A 游戏目录没有写权限。用管理员身份运行，或把输出目录改到别处
  （如程序目录下的 output），再用 Mod Engine 载入。

Q 灵马哨笛 / 望远镜的效果变了
A 那是旧版本生成的文件。用当前版本从干净的原版重新生成，并确认自检通过。

Q 想让骨灰只召一个 / 保留原版多体召唤
A 多召上限设为 1；或选「均衡」预设；或改用「温和」模式（完全不多召）。

Q 召唤出来的敌人太强 / 太多
A 调低血量与伤害倍率（或关掉「应用召唤物倍率」），并调低多召几率。

Q 「设置串」是什么
A 与 Elden Ring Summon Randomizer 的设置串完全互通：可粘贴别人的来
  「应用」，也可「导出」给他人。

Q 装了原版 Summon Randomizer，还需要它吗
A 不需要，本工具功能是它的超集；两者都改 regulation.bin，不要同时使用。

Q 反复点「开始随机化」会越滚越大吗
A 完整模式会自动清理上一轮的克隆行；最稳妥是以原版为输入、固定种子运行。

Q 装了 Unlocked Ashes of War，还需要吗
A 不需要，本工具的「解除战灰武器限制」机制与之相同。

Q 对话飞速掠过、看不清
A 这是对话随机（全量实现）的固有现象：动作/口型/时间会随台词一起搬。
  只影响播放节奏，不影响任务逻辑；介意就关掉该项。

Q 法术名称 / 图标变了吗
A 不会。只改效果字段，名称与图标不在修改范围。

Q 支持其他游戏版本吗
A 参数表定义基于 1.14/1.16 一代，已在 1.16 验证；版本结构变化需另配 paramdefs。

七、与其他随机化器一起用
----------------------------------------------------
mod 分两类：文件型（生成一套游戏文件，如 Elden Ring Randomizer 428、本工具）
与 dll 型（运行时挂钩，如 Nexus 97）。两者分工：
  428     改「世界里有什么」：拾取物/宝箱、商店、掉落、出身、敌人摆放、
          钥匙物品成链（自带求解器）
  本工具  改「东西有什么用」：效果链、召唤物、对话、动作、攻击元素、
          敌人抗性与韧性

推荐顺序（本工具只在 428 的产物上做参数级加工）：
  1) 按 428 的说明完成完整随机化
  2) 本工具的「游戏目录」和「输出目录」都指向 428 的输出目录（就地加工）
  3) 用 428 的启动器进游戏
  注意：之后不要再重跑 428（会覆盖加工结果）；本工具只改 regulation.bin，
  428 的地图 / 事件 / 文本原样保留。

备选（428 的 merge 方向）：先跑本工具，再用 428 的「Merge other mod」合并。
风险：本工具的召唤物会新增行，428 对新增行的处理未知——走这条路线建议
关闭召唤物随机化。

与 dll 型（如 Nexus 97）：叠加等于双重随机，建议二选一；若要同用，在它的
randomiserpreferences.ini 里把与本工具重复的表关掉（如 TalkParam、
EquipParamWeapon、EquipParamGoods、Magic）。

八、命令行工具（可选，进阶排障用）
----------------------------------------------------
  ErringulatorCN.Cli.exe randomize   --input <原版目录> --output <输出目录>
  ErringulatorCN.Cli.exe compare     --input <A> --output <B>      逐表差异
  ErringulatorCN.Cli.exe verify      --input <原始> --output <生成>  改动汇总
  ErringulatorCN.Cli.exe safetycheck --input <原始> --output <生成>  关键道具自检
  ErringulatorCN.Cli.exe summons     --input <原始> --output <生成>  召唤物专项校验
  （--defs 可显式指定 paramdefs 目录，默认查找 exe 同层）
